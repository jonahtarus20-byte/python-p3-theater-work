# Moringa Theater Work

#### Date, 2025/12/06

#### By *JONAH TARUS*

## Description
It's a Python project that models a theater audition system using SQLAlchemy. 
Actors can audition for roles, and roles can have multiple auditions. 
The project includes functionality to track leads, understudies, and audition locations.

## Installation Requirements
- Python 3
- Pipenv

### Installation
git@github.com:jonahtarus20-byte/python-p3-theater-work.git
pipenv install
pipenv shell
